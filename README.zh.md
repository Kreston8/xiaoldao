# 小灵岛 for Android

[English](README.md) | 中文

小灵岛是一个 Android 通知岛：屏幕顶部一颗黑色胶囊，需要看的消息才弹开；桌面还有一个更小的常驻药丸。
纯 Java，两个 overlay 窗口，没有 WebView，除了功能本身需要之外不做后台轮询。

灵感来自 [islandcn](https://github.com/opencoredev/islandcn)（MIT，(c) 2026 Leo，那是一个 Next.js
站点加一套 shadcn registry，不是 App）。这里的每一行 Android 代码都是为本项目写的，没有复制
islandcn 的任何内容，见 [NOTICE](NOTICE)。

## 显示什么

| 卡片 | 触发 | 内容 |
|---|---|---|
| 消息 | 微信／QQ／短信通知 | 头像或图标、发送者、一行正文 |
| 验证码 | 通知或短信里的验证码样式数字 | 只显示验证码，大字，带复制按钮 |
| 取件码 | 短信里出现「取件码／取货码／提货码」 | 取件码和取件点，点一下跳到那条短信 |
| 快递 | 派送中／已签收／即将送达 | 快递公司的原话和预计到达 |
| 待办 | 小米笔记的提醒（需要 root，见下） | 事项和时间 |
| 电话 | 来电／闹钟 | 号码或联系人，点一下回到通话界面 |
| 音乐 | 网易云音乐在放 | 歌名、歌手、进度和当前那句歌词 |
| 常驻药丸 | 桌面 | 时钟、天气、电量 |

点胶囊打开来源应用，双击复制卡片文字，左滑关闭。长按会让它抖，抖着往上滑就隐藏三分钟。
常驻药丸上的手势一样，长按是复制它当前显示的内容。

## 安装

1. 打开 [Releases](../../releases) 下载最新的 `xiaoldao-*.apk`。
2. 安装。MIUI 会让你允许来自此来源的安装。
3. 打开应用，一行一行授权：悬浮窗权限、通知使用权，需要哪些卡片再开短信权限、电话权限、
   使用情况访问。
4. MIUI 里再做三件事：应用管理 → 小灵岛 → 权限 → 后台弹出界面 打开；省电策略 → 无限制；
   自启动 打开。这三样不开，退出应用后小灵岛就回不来了。

只有一个通用安装包，不拆 ABI，没有 native 库。

## 做不到的事

- **待办卡片**只能读小米笔记（`com.miui.notes`）。它不提供 provider，所以是直接读数据库，需要
  root。没有 root 时这个开关不起作用，设置页里也写清楚了。
- **蓝牙电量在 2.16 里被删掉了。** Android 没有公开的配件电量接口（`BATTERY_LEVEL_CHANGED` 需要
  `BLUETOOTH_PRIVILEGED`），只有经典蓝牙的耳机又只在自己的私有协议里报电量，与其留一个可能永远
  没有数字的芯片，不如把功能、界面和那两个蓝牙权限一起删掉。
- **天气**要手填城市，不申请定位权限。点温度会打开小米天气；MIUI 必须允许「后台弹出界面」，
  否则这次跳转会被静默丢弃。
- **电话**：Android 12 起不再把号码交给第三方应用，卡片显示来电界面暴露的内容，点一下回到通话页。
- **短信**卡片打开的是会话，不是某一条。
- **歌词**来自 `music.163.com`，曲库里没有的歌只显示歌名和歌手。
- 胶囊不会画到状态栏之上，锁屏时隐藏。

## 网络

四个域名，都只在用到时才连：`geocoding-api.open-meteo.com`、`api.open-meteo.com`、
`air-quality-api.open-meteo.com`（手填城市，缓存 30 分钟）和 `music.163.com`（歌词）。
没有统计、没有登录、没有别的流量。

## 构建

每次改动 `android/**` 的推送都会在 CI 上构建并发版。本地也是一样的 Gradle 工程：

```
cd android
gradle assembleRelease          # 需要 JDK 17 和带 platform 34 的 Android SDK
```

版本号 `2.<批次>.<run 号>`，`versionCode = 1000 + <run 号>`，所以从这个仓库出的包永远能覆盖
旧的 `islandcn` 分支出的包。

权限、每一个开关和完整的限制清单在 [android/README.zh.md](android/README.zh.md)
（[English](android/README.md)）。
